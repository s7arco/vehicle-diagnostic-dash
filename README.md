# vehicle-diagnostic-dash
A tool that emulates an OBD Reader, it displays ODB-II data from a cars ECU and displays the data on a dashboard for analysis.

Started this project due to fascination on how ODB Scanners work

## Project status
 
 In development - dashboard is currently being developed using simulated data since I dont own a OBD-II adapter, next stage is to integrate live data.

## Completed Features
- Live vehicle dashboard
- Simulated real-time vehicle data
- Engine RPM monitoring
- Vehicle speed monitoring
- Coolant temperature monitoring
- Engine load monitoring
- Throttle position monitoring

## Planned Features
- OBD-II integration
- Live ECU Data
- Fault Code reading
- Diagnostics Trouble code reading
- Vehicle data history


## Tools

- Python
- OBD-II
- Streamlit
